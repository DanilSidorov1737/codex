# Coverage of the original fork text

This tracks all38 capability sections in [Codex CLI Fork.txt](../Codex%20CLI%20Fork.txt).
It is an evidence map, not a claim that every bullet is implemented. The qualified
baseline is3eca8520e0. The daily-use batch is still in progress; prototypes and
pending native checks are identified explicitly. No completion percentage follows
from counting rows or test cases, since their scope and complexity differ.

**Bounded** means a useful local subset has actual release evidence. **Partial**
means important requested capabilities still remain. **Deferred** means the owner
has postponed the relevant external integration/authority. Earlier release proof
is in [adaptive qualification](adaptive-qualification.md); current candidate proof
is in [daily-use qualification](daily-use-qualification.md).

Actual official Neovim remains mandatory and optional to open. Follow AI, native
diff/three-way views, independent edits, selections, owner test terminals and
bounded tab/window checkpoints have baseline evidence. General simultaneous
shared-buffer editing and arbitrary plugin/LSP compatibility are not claimed.
Daily-use tasks36–38 extend compatibility, abrupt dirty-editor recovery and
bounded conflict proposals. The five layouts remain Console, Workspace, Projects,
Operations and Review; this map introduces no required roles or sixth layout.

Keep this table current after each qualified slice. Link new implementation and
actual evidence, distinguish proposals from runtime behavior, and retain explicit
deferrals. The full vision includes many intentionally deferred external domains;
the approved forty-task batch does not complete every bullet automatically.
